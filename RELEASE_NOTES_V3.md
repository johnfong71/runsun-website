# RunSun English Website V3 Preview — 2026-11-11

## Purpose
This is a preview-only editorial and design revision, published from the existing runsun-website-v2 branch. The production main branch and Japanese site are unchanged.

## Changes since V2
- Recolored the abstract full-stack architecture diagrams in RunSun logo orange (#FF6000) on light backgrounds. Photographic / NVIDIA hardware imagery remains unchanged.
- Updated process-diagram accents and numbered steps to the RunSun orange family.
- Added a prominent AI Factory positioning statement beneath the homepage headline.
- Added a three-way deployment comparison: Public AI Cloud, RunSun Proprietary AI Factory, and self-owned On-Premises AI Factory.
- Explicitly explains the value of dedicated capacity, planned elasticity and managed operations without promising unlimited instant scaling.
- Added a two-part explanation of enterprise/private and public data flywheels, clarifying permissioned external data sharing.
- Refined the hero and infrastructure description to prioritize RunSun's NVIDIA GPU infrastructure and AI Factory delivery role.
